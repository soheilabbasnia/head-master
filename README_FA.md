یک نرم‌افزار سبک، کاربردی و ماندگار برای **مدیریت تسک‌ها و فعالیت‌های روزانه (Task Management)** در محیط خط فرمان و ترمینال، توسعه‌یافته با زبان **پایتون (Python)**، دیتابیس بومی **SQLite3** و کتابخانه **Colorama**.

---

## نمای کلی پروژه

مدیریت وظایف و یادداشت‌های کاری بدون خروج از محیط ترمینال، تمرکز و بهره‌وری برنامه‌نویسان را به شکل چشمگیری افزایش می‌دهد. **هدمستر (HeadMaster)** یک شل تعاملی کنسول در اختیار شما قرار می‌دهد تا بتوانید فهرست کارهای روزانه خود را در یک دیتابیس محلی ذخیره، ویرایش و مدیریت کنید.

نکات برجسته:
- **پایگاه‌داده پایدار محلی:** ذخیره‌سازی مطمئن وظایف در دیتابیس SQLite بدون نیاز به اینترنت یا سرور جداگانه.
- **محیط خط فرمان تعاملی (REPL):** پرامپت سریع و هوشمند با پشتیبانی از کلیه دستورات مدیریت تسک.
- **رابط بصری رنگی و انیمیشن لودینگ:** استایل‌بندی زیبای متن‌ها و اعلان‌ها با رنگ‌های ANSI و افکت چرخان (Spinner).
- **مدیریت دفاعی خطاها:** ساخت خودکار جداول دیتابیس، بررسی بازه شناسه‌ها و جلوگیری از کرش برنامه در ورودی‌های خالی.

---

## دستورات و قابلیت‌های اصلی

| دستور | عملکرد | توضیحات |
| :--- | :--- | :--- |
| `list` | مشاهده تسک‌ها | نمایش تمام وظایف ثبت‌شده همراه با شناسه یکتای دیتابیس |
| `add` | افزودن تسک | دریافت متن تسک و ذخیره آن در پایگاه داده SQLite |
| `edit` | ویرایش تسک | به‌روزرسانی متن یک تسک بر اساس شماره شناسه |
| `remove` | حذف تسک | حذف ایمن تسک انجام‌شده با شناسه مشخص |
| `cls` | پاکسازی صفحه | پاک کردن صفحه کنسول برای ایجاد محیطی خلوت و مرتب |
| `restart` | راه‌اندازی مجدد | ریست کردن ارتباطات پایگاه داده و بارگذاری دوباره حلقه برنامه |
| `exit` | خروج | خروج استاندارد و تمیز از برنامه |

## نحوه نصب و راه‌اندازی

### پیش‌نیازها

- پایتون نسخه ۳.۷ یا بالاتر
- کتابخانه `colorama`

### مراحل اجرا

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/soheilabbasnia/head-master.git
   cd head-master
   ```

۲. **نصب وابستگی:**
   ```bash
   pip install colorama
   ```

۳. **اجرای هدمستر:**
   ```bash
   python3 program.py
   ```
